# Multi-Page Static Website Template

A multi-page static website template/prototype developed using **HTML, CSS, and JavaScript**. This template is designed for business, portfolio, or personal websites, including multiple pages and interactive UI components.

---

## Project Overview

This project contains core pages typically found in professional websites, such as:

- **Home** (`index.html`)
- **About** (`about.html`)
- **Services** (`services.html`)
- **Contact** (`contact.html`)

The design emphasizes **UI widgets, maps, and interactive components**, with additional HTML templates showcasing various functionalities.

---

## Key Features and Pages

### Index.html
- Main landing page with hero sections and highlights.
- Interactive UI components for engagement.
- Navigation to other pages.

### About.html
- Background information about the individual, company, or project.
- Sections like mission, vision, team, and history.

### Services.html
- Details about services or products offered.
- Pricing information and service categories.

### Contact.html
- Contact form for inquiries.
- Contact information (phone, email, address).
- Map integration for office location.

### UI Widgets and Maps
Additional pages demonstrate UI components and map libraries:
- `ui-widgets-pricing.html`, `ui-widgets-todolist.html`, `ui-icons-fontawesome.html`
- `ui-map-leaflet.html`, `ui-map-google.html`, `ui-map-openlayers.html`

These pages show how to embed **interactive features** and **visual widgets** into your website.

---

## Technical Stack

**Frontend:**
- HTML, CSS, JavaScript
- Icon libraries (e.g., FontAwesome)
- Open-source map libraries (Leaflet, Google Maps, OpenLayers)

**Build Tools:**
- [Vite](https://vitejs.dev/) for bundling and live reloading
- Dependencies managed via `yarn` or `npm`
- `package.json` and `yarn.lock` for package management
